# Seguridad

TicketIA es un proyecto personal desarrollado por afición y compartido con fines educativos y experimentales.

## Sin soporte de seguridad

Este proyecto no ofrece soporte de seguridad, mantenimiento garantizado ni plazos de respuesta.

El autor no se compromete a:

- Revisar todos los informes o avisos de seguridad.
- Responder a todas las comunicaciones recibidas.
- Corregir vulnerabilidades.
- Publicar actualizaciones o parches.
- Mantener versiones anteriores o futuras.
- Garantizar que el software sea seguro, estable o adecuado para un uso concreto.

Los informes, incidencias y propuestas podrán ser revisados o ignorados libremente, según el tiempo, interés y disponibilidad del autor.

## Uso bajo tu responsabilidad

El software se proporciona «tal cual», sin garantías de ningún tipo.

Cada usuario es responsable de evaluar los riesgos antes de instalar, publicar o utilizar TicketIA, especialmente en entornos accesibles desde Internet o que manejen información sensible.

No debe asumirse que el proyecto ha sido auditado profesionalmente ni que está libre de vulnerabilidades.

## Avisos de seguridad

Quien descubra un posible problema de seguridad puede comunicarlo mediante GitHub Security Advisories, pero no existe garantía de revisión, respuesta o corrección.

No incluyas credenciales, datos personales, secretos ni información sensible en issues públicos.
